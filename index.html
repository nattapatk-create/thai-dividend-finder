Thai Dividend Stock Finder SET · mai — ราคาจริงจาก EODHD

เชื่อมต่อ API ราคาจริง

แอปนี้ดึง "ราคาปิดล่าสุด" จริงจาก EODHD ผ่าน proxy กลาง (แผนฟรี: 20 คำขอ/วัน, ไม่ใช่ราคาเรียลไทม์) API key ของ EODHD ถูกเก็บเป็นความลับไว้ที่ฝั่งเซิร์ฟเวอร์ของ proxy เท่านั้น — แอปหน้าบ้าน (ไฟล์นี้) ไม่ต้องขอ ไม่เก็บ และไม่ส่งคีย์ใดๆ ออกจากเบราว์เซอร์ของคุณเลย จึงไม่มีความเสี่ยงที่คีย์จะรั่วไหลผ่านหน้าเว็บที่เผยแพร่ต่อสาธารณะ

เชื่อมต่อผ่าน proxy แล้ว — พร้อมดึงราคาจริง

รายชื่อหุ้นทั้งตลาด

โหลดครั้งเดียวพอ (เก็บไว้ในเครื่อง) หลังโหลด พิมพ์ค้นหาชื่อหุ้นที่ยังไม่อยู่ในรายการได้เลย

หมายเหตุ: ไม่มี API ฟรีเจ้าไหนให้ "ประวัติปันผล" ของหุ้นไทยแบบละเอียด — ตารางปันผลในรายการหุ้นเป็นข้อมูลตั้งต้นที่ แก้ไขได้เอง ระบบจะจำค่าไว้ในเครื่องอัตโนมัติ

คำขอทั้งหมดไปยัง EODHD วิ่งผ่าน proxy ที่กำหนดใน EODHD_BASE เท่านั้น proxy จะตรวจสอบปลายทางกับ whitelist ก่อนส่งต่อทุกครั้ง (ดู proxy-worker.js)

รายชื่อหุ้น คลิกที่แถวเพื่อดู/แก้ไขประวัติปันผล และดึงราคาจริง

ไม่พบหุ้นที่ตรงกับเงื่อนไขการค้นหา

เครื่องคำนวณเงินปันผล คำนวณจากเงินปันผลต่อหุ้นล่าสุดในตารางของแต่ละหุ้น

ราคาหุ้นที่ใช้คำนวณ–
จำนวนหุ้นที่ถืออยู่ / ซื้อได้–
เงินลงทุนจริง (ปัดเศษหุ้นลง)–
เงินสดคงเหลือ–
เงินปันผลต่อหุ้นล่าสุด–
เงินปันผลรวมก่อนหักภาษี–
หักภาษี ณ ที่จ่าย 10%–
เงินปันผลรับสุทธิ (หลังหักภาษี)–
Dividend Yield ส่วนตัว (หลังภาษี)–
ตามประมวลรัษฎากร เงินปันผลจากหุ้นสามัญที่จ่ายให้ผู้ถือหุ้นบุคคลธรรมดาถูกหักภาษี ณ ที่จ่ายในอัตรา 10% — สูตร: เงินปันผลสุทธิ = เงินปันผลรวม × (1 − 0.10), Yield ส่วนตัว = (เงินปันผลสุทธิ ÷ เงินลงทุน) × 100

เกี่ยวกับข้อมูล: ราคาหุ้นดึงจาก EODHD API จริงผ่าน proxy กลาง (แผนฟรีจำกัด 20 คำขอ/วัน เป็นราคาปิดของวันทำการล่าสุด ไม่ใช่ราคาระหว่างวันแบบเรียลไทม์) API key ของ EODHD ถูกเก็บไว้เป็นความลับที่ฝั่งเซิร์ฟเวอร์ของ proxy เท่านั้น ไม่เคยถูกส่งมาหรือเก็บไว้ในเบราว์เซอร์ของคุณ หากเรียก API ไม่สำเร็จ ระบบจะใช้ราคาสำรองแทนและระบุไว้ชัดเจนด้วยป้าย FALLBACK
ประวัติเงินปันผลเป็นตารางที่แก้ไขได้เอง — แถวที่ยังไม่ได้แก้จะมีป้าย SEED DATA กำกับไว้เพราะเป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลจริง กดที่ตัวเลขในตารางเพื่อแก้เป็นค่าจริงที่คุณเช็คมา (แถวจะเปลี่ยนเป็น "ยืนยันแล้ว") ระบบบันทึกอัตโนมัติในเบราว์เซอร์ของคุณ (localStorage) ไม่มีการส่งข้อมูลนี้ไปที่ใด

ความหมายของป้ายกำกับ: LIVE = ราคาจริงจาก API  ·  FALLBACK = ราคาสำรอง ไม่ใช่ราคาจริง  ·  SEED DATA = ข้อมูลตัวอย่าง ยังไม่ได้ตรวจสอบ
